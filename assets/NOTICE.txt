Browser conversion: fixed NCHW 1x3x576x576, scale1, ONNX opset17. Conv/FFN/residual weights and operations use FP16; LayerNorm and attention arithmetic use FP32 (qkv/project Conv remain FP16), FP32 input/output. No retraining, INT8 quantization, image downsampling, or GELU approximation. PixelUnshuffle exports to Reshape/Transpose. Initializers use IEEE half conversion, without converter small-constant clipping. LayerNorm/attention epsilon stays FP32. Original Clip remains FP32; rejected all-half/Max conversion is not distributed.
Converted ONNX SHA256: aa84f9dab6d432da4a3a1ad670d771cb85740f51a5541fa1050461ea891e35bf
Converted ONNX bytes: 55434277, split into 8MiB parts for static delivery. Every part and the assembled model are checked against fixed hashes.
Runtime: ONNX Runtime Web 1.31.1 native WebGPU EP / Asyncify. See LICENSE-ONNX-Runtime.txt and ThirdPartyNotices-ONNX-Runtime.txt.

Application adaptation: exact original photo pixels in encoded sRGB/255; no perspective resample before inference. Global source grid stride160; tile576; core320; context128; reflect101 only at true photograph boundaries. Residual high-pass is residual minus separable Gaussian sigma4/radius16, applied at strength0.5. Four overlapping cores use raised-cosine weights. Floating point values remain unclamped until the final ordinary Engine render/8bit encoding.
Attention depends on each tile's entire context. Overlap reduces seams but is not proof of whole-image equivalence or of faithful recovery. The model can alter marks and texture, and can worsen already sharp or compression-only images. It is optional, initially off, and must be judged against ordinary processing at the same output dimensions and view.

Photos and settings are not uploaded. The dedicated worker fetches only fixed model/runtime files from the same site. There is no paid API or automatic CPU/ordinary fallback for this model.
